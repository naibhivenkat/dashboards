Grocery App

Grocery App is an online grocery ordering platform where customers can place orders from nearby shops using a mobile application.

How the App Works

  1. User registers and logs in
  2. Selects a nearby grocery shop
  3. Adds items to cart
  4. Makes payment using Razorpay
  5. Shop owner prepares and delivers the order

Platforms

  • Android App
  • Flutter App

Payment Gateway

Payments are processed securely using Razorpay.
