Grocery App

Grocery App is an online grocery ordering platform where customers can order groceries from nearby shops using a mobile application.

Key Features

  • User login & registration
  • Shop selection
  • Cart & order management
  • Online payments using Razorpay
  • Order tracking & delivery

How It Works

  1. User logs in
  2. Selects a shop
  3. Adds items to cart
  4. Completes payment via Razorpay
